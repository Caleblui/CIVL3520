Earned value

CV = EV − AC (− = over budget) SV = EV − PV (− = behind schedule) CPI = EV / AC (<1 = over budget) SPI = EV / PV (<1 = behind) EV = % complete × BAC EAC = BAC / CPI current efficiency continues EAC = AC + (BAC − EV) problem was one-off, back to plan EAC = AC + bottom-up ETC new detailed estimate ETC = EAC − AC Required CPI = (BAC − EV) / (money left for remaining work)

Risk

EMV = probability × impact (threat +, opportunity −) Net EMV = Σ EMV Risk-adjusted EAC = base EAC + net EMV Response expected cost = certain cost + p_new × impact_new

CPM with lags (forward pass, take the MAX)

FS/x : ES_j ≥ EF_i + x SS/x : ES_j ≥ ES_i + x FF/x : EF_j ≥ EF_i + x → ES_j ≥ EF_i + x − d_j ES never below 0. Project end = largest EF of ANY activity.

Backward pass (take the MIN)

FS/x : LF_i ≤ LS_j − x SS/x : LS_i ≤ LS_j − x → LF_i ≤ LS_j − x + d_i FF/x : LF_i ≤ LF_j − x LF never above project end. TF = LS − ES = LF − EF

Free float (smallest gap to any successor)

FS/x gap = ES_j − EF_i − x SS/x gap = ES_j − ES_i − x FF/x gap = EF_j − EF_i − x No successor: FF = project end − EF_i

PERT probability

σ_project = √(Σ variances on critical path) ← add VARIANCES, not σ z = (T − μ) / σ P(finish ≤ T) = 0.5 + table(z) if T > μ = 0.5 − table(|z|) if T < μ Target confidence: 90% → table 0.40 → z ≈ 1.28 → T = μ + 1.28σ

Crashing

slope = (crash cost − normal cost) / (normal dur − crash dur) Total cost = direct + overhead/day × duration Crash while slope (combined) < overhead per day saved

Estimating & selection

Capacity factor: C_new = C_old × (Q_new / Q_old)^e Escalation: C_future = C_now × (1 + r)^n Location: × (index_new / index_old) Payback period: time until cumulative inflows = investment Burgess: smoothness = Σ R² (lower is smoother)
Given in the exam

You will have these, but know how to use them

te = (o + 4m + p) / 6 σ² = ((p − o) / 6)² i = rate per period (6% p.a. monthly → 0.06/12 = 0.005), n = number of periods FV = −PV (1+i)^n PV = −FV / (1+i)^n PV = −PMT [1 − (1+i)^−n] / i FV = −PMT [(1+i)^n − 1] / i PMT = −i·PV / [1 − (1+i)^−n] PMT = −i·FV / [(1+i)^n − 1] n = ln[(1 + i·PV/PMT)^−1] / ln(1+i) n = ln[1 − i·FV/PMT] / ln(1+i) Received = +, paid = −. The minus signs only flip direction.
